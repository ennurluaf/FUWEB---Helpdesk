# FUWEB helpdesk starter

This classroom starter contains one deliberate request fault for week 1.

1. Open a terminal in this folder.
2. Run `npm install`.
3. Run `npm start`.
4. Visit http://localhost:3000 (do not open index.html directly).
5. Use the week 1 instructions to investigate.

Stop with Ctrl+C. Restart after server edits. Data is in memory; this is a local classroom prototype.
